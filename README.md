## GitHub Pages

This repository contains only the static public website, not the Unity project.
Publish branch `main`, directory `/(root)`, with HTTPS enabled.

- Home: https://piralihaider.github.io/Paintivo-public/
- Privacy Policy: https://piralihaider.github.io/Paintivo-public/privacy.html
- Terms of Use: https://piralihaider.github.io/Paintivo-public/terms.html

These addresses become accessible after a successful GitHub Pages deployment.
The HTML is buildless, contains no JavaScript or third-party ad/analytics tags,
and serves its images and font locally. No app IDs or credentials are included.

The policies describe the current app and must be kept consistent with released
features and SDK behaviour. Publishing a policy does not itself certify legal,
children's advertising, consent, or Google Play Data safety compliance.
