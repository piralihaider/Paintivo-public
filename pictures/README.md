# Paintivo picture downloads

This collection contains **200 extra colouring pictures**, grouped into **20 batches of 10**. Another **100 pictures are included in the app**. This is not yet a 1,000-picture collection.

- Catalogue: `catalogue.json`
- Direct HTTPS endpoint: `https://raw.githubusercontent.com/piralihaider/Paintivo-public/main/pictures/catalogue.json`
- Each entry links to an immutable versioned manifest and individual PNG downloads.
- Full-size images are 1600 × 1600; previews are 256 × 256.
- Original page IDs and file bytes are preserved so existing saved colouring remains compatible.
- The app verifies manifest and image SHA-256 hashes and sizes before installation.

These are original Paintivo project drawings. Creator, source and licence labels are included in each picture's metadata. Public availability does not imply that unrelated artwork may be copied or that these pictures have a general open-source copyright licence. See the repository's Paintivo terms for app-use terms.

In the updated app, opening a downloaded picture for colouring retains its original on the device. Unopened session downloads are cleared at normal exit or the next launch after a force-close. Editable artwork and exported gallery images are stored separately and are not removed by this cleanup.

To add more artwork, prepare reviewed batches of 10 with distinct permanent page IDs, monochrome closed outlines, provenance and redistribution permission. Never replace a published outline under an existing page ID.
